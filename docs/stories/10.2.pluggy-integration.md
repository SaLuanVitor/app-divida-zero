# Story 10.2: Pluggy Integration — Connect Widget, Webhooks & Sync

## Status
InReview

## Story
**As a** usuário do App Dívida Zero,
**I want** conectar minhas contas bancárias via Pluggy Connect Widget e ter sincronização automática via webhook,
**so that** eu veja minhas transações atualizadas sem importar arquivos manualmente.

## Acceptance Criteria
1. Endpoint `POST /api/v1/financial/connections` cria `FinancialConnection` e retorna `connect_token` + `connect_url` para o Connect Widget
2. Frontend (Expo/React Native) abre Connect Widget em WebView com o token recebido
3. Webhook `POST /webhooks/pluggy` processa eventos: `item/created`, `item/updated`, `item/error`, `item/deleted`, `transactions/created`, `transactions/updated`, `transactions/deleted`
4. `WebhookProcessingJob` enfileirado via Solid Queue processa webhook de forma assíncrona e idempotente
5. `FinancialSyncJob` executa sincronização completa: busca accounts + transactions → normaliza → salva → atualiza `FinancialSync`
6. Sincronização manual via `POST /api/v1/financial/connections/:id/sync` dispara `FinancialSyncJob`
7. Polling fallback: job recorrente (via `config/recurring.yml`) sincroniza conexões sem webhook a cada 6 horas
8. Tratamento de erros: `item/waiting_user_input`, `item/waiting_user_action` atualizam status da connection
9. Deduplicação: usar `Bank::DeduplicationService` + `fit_id` do Pluggy para evitar duplicatas
10. Categorização: usar `Bank::AiCategorizationService` nas transações novas
11. Testes de integração: webhook processing, sync job, connect token generation

### Pluggy Connect Widget Flow
1. Backend: `POST /connect_token` com `clientUserId` = `user.id` + `itemId` (opcional para update)
2. Frontend: Abre `https://connect.pluggy.ai/?connectToken={token}` em WebView
3. Usuário: Seleciona banco → autentica (MFA) → autoriza
4. Pluggy: Dispara webhook `item/created` → Backend processa → `FinancialSyncJob` roda
5. Frontend: WebView detecta fechamento → chama `GET /connections/:id` → atualiza UI

### Webhook Signature Verification
```ruby
# Pluggy envia header: Pluggy-Signature: sha256=...
# Verificar:
expected = OpenSSL::HMAC.hexdigest('SHA256', PLUGGY_WEBHOOK_SECRET, request.body.read)
provided = request.headers['Pluggy-Signature'].split('=').last
ActiveSupport::SecurityUtils.secure_compare(expected, provided)
```

### Idempotência Webhook
```ruby
# Pluggy envia event_id único por evento
# Armazenar em Redis/DB: processed_webhook_events
# Se já processado, ignorar
```

### Sync Incremental vs Full
- **Full**: primeira sincronização ou `item/updated` com mudança de credenciais
- **Incremental**: `transactions/created/updated/deleted` → buscar só transações novas/alteradas (params `updatedAfter`)
