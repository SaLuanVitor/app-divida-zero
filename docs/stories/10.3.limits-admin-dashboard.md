# Story 10.3: Limits, Plans & Admin Health Dashboard

## Status
Done

## Story
**As a** administrador do App Dívida Zero,
**I want** sistema de limites por plano, feature flags e dashboard de saúde do provider,
**so that** eu controle uso, evite custos inesperados e monitore a integração bancária.

## Acceptance Criteria
1. `Plan` + `PlanLimit` + `FeatureFlag` funcionando com seed inicial: plano `free` (10 users, 20 connections total, 3/user, 15 accounts/user, 10k transações/mês, sync manual 2x/dia)
2. Service `Limits` com métodos: `allowed?(user, resource, action)`, `remaining(user, resource)`, `exceeded?(user, resource)`
3. Validação automática em `FinancialConnectionsController#create` → bloquear se limite excedido (403 com mensagem clara)
4. UI mostra barra de progresso: "Conexões bancárias ████████░░ 8/10 — Limite do plano gratuito: 10"
5. Aviso aos 80%: "Você está próximo do limite de conexões. 8 de 10 utilizadas."
6. Bloqueio aos 100%: "Você atingiu o limite do plano gratuito. Desconecte uma instituição para conectar outra."
7. Admin Dashboard (`/admin/financial`) mostra:
   - Provider status: Pluggy ● Online / ○ Offline (último ping)
   - Connections: 17/20 (total/limite)
   - Users: 8/10
   - Último sync bem-sucedido: 14:32
   - Erros nas últimas 24h: 2
   - Queue depth: 3 jobs pendentes
8. Feature Flags controlam: `open_finance`, `bank_sync`, `investments`, `credit_cards`, `family`, `ai_analysis`, `manual_import`
9. Configuração via banco (table `settings`) ou ENV — alterável sem deploy
10. Testes: Limits service, controller validation, admin dashboard, feature flags

### LimitsService Logic
```ruby
def allowed?(user, resource, action)
  plan = user.plan || Plan.free
  limit_key = "#{resource}.max_#{action == :create ? 'per_user' : 'total'}"
  limit = plan.limits.find_by(key: limit_key)&.value.to_i
  current = usage(user)[resource]
  current < limit
end

def usage(user)
  {
    connections: user.financial_connections.active.count,
    accounts: user.financial_accounts.count,
    transactions_this_month: user.financial_records.this_month.count,
    syncs_today: user.financial_syncs.today.count
  }
end
```
